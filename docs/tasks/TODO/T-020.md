# T-020: デコード精度設定の見直し（Scope C: fallback/beam 等）

## 目的
- これまで速度優先で抑えていたデコード設定（`DecodingPresets.japanese`）を、M5 Pro の余力で
  精度寄りに調整する。旧 Sprint で保留していた Scope C。

## 受け入れ条件
- [ ] `temperatureFallbackCount` を 0 → 1〜2 にし、低確信セグメントの再評価で誤りが減る。
- [ ] （任意）ビーム探索や `compressionRatioThreshold`/`logProbThreshold` の調整を検討・記録。
- [ ] 変更で 1 回の decode が重くなっても pipeline ms が budget 内（T-015 計測）。
- [ ] 代表音声で精度改善を定性確認。無音幻聴が増えていないこと。

## 影響範囲
- `STTLocalApp/Speech/DecodingPresets.swift`

## 制約・前提
- fallback/beam は decode コストを増やす＝レイテンシと逆方向。計測しながら。
- 依存: T-015（計測）、T-017（モデル確定後が望ましい）。
- 設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] 計測で budget 内・精度改善・幻聴増なしを確認
