# T-019: 計算ユニット .all（GPU併用）の検証

## 目的
- 現状 ANE のみ（`.cpuAndNeuralEngine`）の compute を `.all`（CPU+GPU+ANE）にして、
  encode/decode のスループット向上・pipeline ms 短縮が得られるか検証する。M5 Pro の GPU を活用。

## 受け入れ条件
- [ ] `ModelComputeOptions` を `.all`（または audioEncoder を GPU 寄り）に変更して動作する。
- [ ] 変更前後で `[STT/timings]` の encode/pipeline ms を比較し、改善有無を定量記録。
- [ ] 改善が無い/悪化する場合は ANE のみへ戻す判断を記録（CoreML は構成依存で GPU が遅い場合あり）。
- [ ] 消費電力/発熱の体感が許容範囲（ノート運用のため）。

## 影響範囲
- `STTLocalApp/Speech/WhisperEngine.swift`（`ModelComputeOptions`）

## 制約・前提
- compute units はモデルロード時設定。変更時は再ロードが要る点に留意。
- 依存: T-015（計測）。設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] encode/pipeline ms の前後比較を記録し、採用/不採用を判断
