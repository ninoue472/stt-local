# T-026: モデル選択UI（メニューバー）＋ 量子化既定で軽量化（M1対応）

## 目的
- 日本語精度を保ったまま軽量化し、M1/8GB でも快適に使えるようにする。
- ユーザーがハード/用途に応じてモデルを選べるようにする。Issue #8 の本実装（選択肢 B）。

## 決定事項（人間承認 2026-06-08）
- **UI: メニューバーのメニュー**（既存 `MenuBarContent` に「モデル」セクションを追加）。
- **3段階ラインナップ**（id は WhisperKit/argmaxinc の正確なモデル名）:
  | 表示 | モデル名 | サイズ |
  |---|---|---|
  | 高精度 | `openai_whisper-large-v3_turbo` | 約3GB |
  | **標準（推奨・既定）** | `openai_whisper-large-v3_turbo_954MB` | 約954MB（量子化） |
  | 軽量 | `openai_whisper-small_216MB` | 約216MB |
- **既定モデルを量子化版へ変更**（`Settings.defaultModelName` = `openai_whisper-large-v3_turbo_954MB`）。
  既存の未設定ユーザーは次回起動時に ~954MB を1回DL（軽量化が目的なので許容）。

## 受け入れ条件
- [ ] メニューバーのメニューに「モデル」3択が出る。**現在のモデルにチェック**（✓）が付く。
- [ ] 各項目に表示名＋サイズ目安（例: 「標準（約954MB）」）。
- [ ] 別モデルを選ぶと**再ロード**が走る（未キャッシュなら DL → ロード → `.ready`）。完了まで
      phase は `.downloadingModel`/`.loadingModel` を表示（既存 `prewarmWhisper` の流れを再利用）。
- [ ] **録音中・処理中・ロード中はモデル切替不可**（メニュー項目を無効化、または選択を無視）。
      切替は `.ready`（または `.error`）の時のみ。
- [ ] 選択は **UserDefaults に永続化**され、再起動後も保持（`Settings.modelName`。既に永続化済み）。
- [ ] 既定モデルが量子化版（`openai_whisper-large-v3_turbo_954MB`）。
- [ ] 複数モデルの DL/キャッシュ検出が成立（T-021 の `existingLocalModelFolder` が別モデル名でも効く）。
- [ ] README の「必要環境」を更新（既定 ~954MB／選択でモデル変更可／高精度は約3GB）。

## 設計メモ
- **モデルカタログ**は型付きで一元管理（id=WhisperKitモデル名, displayName, sizeLabel）。UIとSettingsが
  同じ定義を参照する。
- **切替フロー**: メニューで選択 → `Settings.shared.modelName = 新id` → 通知（例 `.reloadModel`）→
  `AppDelegate` が `.ready/.error` の時のみ `prewarmWhisper()` を再実行（新 engine + transcriber を
  作り直し）。`prewarmWhisper` は既に `Settings.shared.modelName` を読むので大きな改修は不要。
- **チェック表示**: メニュー再描画時に `Settings.shared.modelName`（または `AppState.modelName`）と
  各項目 id を比較。
- **ガード**: 録音中の切替はデータ整合とリソースの観点で禁止。メニュー項目を `.disabled` に。
- タイミング/音声パイプライン（`StreamingTranscriber`）には**触らない**（perf T-025 を壊さない）。

## 制約・前提
- WhisperKit モデル名は厳密一致が必要（量子化版の正確名は上表）。`normalizeModelName` は既存挙動を維持。
- 量子化版の日本語精度は実機（M5 Pro）で別途体感確認（Issue #8）。本タスクは選択機構の実装が主目的で、
  精度評価は人間が行う。
- 依存: なし（main 起点）。関連: Issue #8、`docs/knowledge/whisperkit-model-cache-detection.md`。
