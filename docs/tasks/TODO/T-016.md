# T-016: 再推論間隔の短縮/可変化（応答性向上）

## 目的
- 喋ってからライブ文字が出るまでの遅延を縮める。M5 Pro の余力で高頻度再推論を可能にする。

## 受け入れ条件
- [ ] `minNewAudioSeconds` を 2.0 → 1.0（必要に応じ 0.75）へ下げ、ライブ表示の更新が体感で速くなる。
- [ ] `[STT/timings]` の pipeline ms が新 budget を恒常的に下回る（T-015 の計測で確認）。
- [ ] 無音幻聴（定型句）が顕著に増えていない（`HallucinationFilter` で吸収できる範囲）。
- [ ] 同一音声での最終テキストが従来と同等以上（脱落・重複の悪化なし）。

## 影響範囲
- `STTLocalApp/Speech/StreamingTranscriber.swift`（`minNewAudioSeconds`、必要なら可変化）

## 制約・前提
- 過去 T-001/T-004 のリグレッション領域。1値ずつ・単独リバート可能に。
  `docs/knowledge/avoid-mutating-audio-pipeline-timing.md` 厳守。
- バッファ操作は「現在のライブ長」基準を維持（`docs/plan/vad-regression-fix.md`）。
- 依存: T-015（計測）。設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] 計測で budget 内・幻聴増なし・最終テキスト同等を確認
