# T-017: フル large-v3 への切替＋既定モデル見直し（精度向上）

## 目的
- turbo（デコーダ削減版）からフル `large-v3` へ上げ、認識精度を高める。M5 Pro なら重い decode も許容。

## 受け入れ条件
- [ ] `openai_whisper-large-v3`（フル）をロード・動作できる（DL/ローカル両経路）。
- [ ] 既定モデルを turbo のままにするか large-v3 に切替えるかを、計測結果に基づき判断・記録。
- [ ] フルモデルでも pipeline ms が budget 内に収まる構成を確認（収まらなければ窓/間隔で調整）。
- [ ] 代表音声で turbo 比の精度改善（誤認識の減少）を定性確認。

## 影響範囲
- `STTLocalApp/State/Settings.swift`（`defaultModelName` / `normalizeModelName`）
- `STTLocalApp/Speech/WhisperEngine.swift`（必要なら）
- `STTLocalApp/UI/ModelDownloadView.swift`（DL表示。必要なら）

## 制約・前提
- モデル切替で DL サイズ・常駐メモリが増える（64GB なので問題なし）。
- 依存: T-015（計測）。Scope C(T-020) と相互作用するため順序留意。
- 設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] フルモデルで budget 内＋精度改善を確認、既定方針を記録
