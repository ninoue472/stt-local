# T-018: 推論窓・オーバーラップ拡大（文脈・境界精度の向上）

## 目的
- 推論窓を広げてエンコーダに与える左文脈を増やし、窓境界での単語切れ・誤りを減らす。M5 Pro の余力を使う。

## 受け入れ条件
- [ ] `maxWindowSeconds` を 5 → 10〜15 の範囲で調整し、文脈増による精度改善を定性確認。
- [ ] `overlapSeconds` を増やし、窓スライド境界での単語切れ/重複が減る。
- [ ] 窓拡大で encode が重くなっても pipeline ms が budget 内（T-015 計測）。
- [ ] スライド/purge の「現在のライブ長」基準ロジックは不変で、発話スキップが起きない。

## 影響範囲
- `STTLocalApp/Speech/StreamingTranscriber.swift`（`maxWindowSeconds` / `overlapSeconds` / slide）

## 制約・前提
- 窓拡大は1回の推論を重くする＝レイテンシと逆方向。T-016（応答性）と同時に詰める場合は計測でバランス。
- 過去リグレッション領域。`docs/knowledge/avoid-mutating-audio-pipeline-timing.md` 厳守。単独リバート可能に。
- 依存: T-015。設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] 計測で budget 内・スキップ無し・境界精度改善を確認
