# T-015: パフォーマンス計測ハーネス（pipeline/ANE/GPU 可視化）

## 目的
- M5 Pro の余力と現状のボトルネックを可視化し、以降の最適化(T-016〜T-020)を計測駆動で進める基盤。
- 「どこに余力があるか」「変更が pipeline ms をどう動かすか」を定量比較できるようにする。

## 受け入れ条件
- [ ] 既存 `[STT/timings]` ログに、現在の設定値（model / computeUnits / minNewAudioSeconds /
      maxWindowSeconds / overlapSeconds）を併記し、後で構成を識別できる。
- [ ] 1セッションの pipeline ms の代表値（平均/最大/p95 程度）を集計してログ出力 or 簡易表示。
- [ ] budget 超過（pipeline > minNewAudioSeconds×1000）の発生回数をカウントして出力。
- [ ] （任意）録音中の ANE/GPU 使用率の確認手順を `docs/knowledge/` に手順としてまとめる
      （`powermetrics` 等。計測は手動でよい）。

## 影響範囲
- `STTLocalApp/Speech/StreamingTranscriber.swift`（ログ集計のみ。タイミングは不変）
- `docs/knowledge/`（計測手順メモ）

## 制約・前提
- **タイミング中立**: 計測の追加で音声パイプラインの挙動を変えないこと。
- 設計概観: `docs/plan/performance-headroom-m5.md`。

## 完了の定義
- [ ] ビルドが通る
- [ ] 現状構成のベースライン値（平均/最大 pipeline ms、budget超過回数）を1回記録
