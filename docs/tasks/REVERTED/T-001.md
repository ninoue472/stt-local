# T-001: VAD ゲートで無音区間の文字起こしをスキップ

## 目的
- 無音・発話余韻の区間を WhisperKit に渡さないことで、無音ハルシネーション
  （「ありがとうございます」等）の発生源を断つ。spec の対策 A。

## 受け入れ条件
- [ ] `StreamingTranscriber.transcribeStep` で、`pipe.transcribe` 呼び出しの前に
      `AudioProcessor.isVoiceDetected(in:nextBufferInSeconds:silenceThreshold:)` で VAD 判定する。
- [ ] 無声（false）の場合は `pipe.transcribe` を呼ばず、`lastBufferSize` を**更新せず**、
      100ms スリープして return する。
- [ ] 有声の場合のみ既存の処理（`lastBufferSize` 更新 → transcribe → ...）に進む。
- [ ] 閾値は `Settings.shared.silenceThreshold` から取得する。
- [ ] `Settings` に `silenceThreshold: Float` を追加（UserDefaults キー `stt.silenceThreshold`, 既定 0.3,
      `noSpeechThreshold` と同じ getter/setter パターン）。
- [ ] 発話が連続するケースで文字起こしが途切れない（既存挙動を壊さない）。

## 影響範囲
- `STTLocalApp/Speech/StreamingTranscriber.swift`（`transcribeStep` のみ）
- `STTLocalApp/State/Settings.swift`（プロパティ 1 追加）

## 制約・前提
- `AudioProcessor.isVoiceDetected` は WhisperKit 既存 static API（追加実装不要）。
- `lastBufferSize` を無声時に更新してはいけない（更新すると無音中の音声が捨てられ、
  発話再開時に頭が欠ける）。WhisperKit 純正 `AudioStreamTranscriber` の useVAD ブロックと同挙動。
- nextBufferSeconds は既存の算出値（`Float(nextBufferSize) / sampleRate`）を流用。
- T-002 と同じ関数を触るが挿入箇所が異なる。先に本タスクを完了させる。
