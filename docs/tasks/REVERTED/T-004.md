# T-004: VAD ゲート導入のリグレッション修正（遅延 + 波形停止）

## 目的
- T-001（VAD ゲート）で transcribe をスキップするようにした結果、無音中に音声バッファが
  切り詰められず肥大化し、(1)発話再開時に重い (2)波形が固まる、という 2 つのリグレッションが発生した。
  これを解消する。詳細は `docs/plan/vad-regression-fix.md`。

## 受け入れ条件

### A. 無音中のバッファ切り詰め
- [ ] `transcribeStep` の VAD 無声分岐で `pruneSilence(pipe)` を呼び、無音でバッファが伸びた場合に
      末尾マージン（約 1.5 秒）だけ残して `purgeAudioSamples(keepingLast:)` で切り捨てる。
- [ ] purge 前に `confirmedSegments + unconfirmedSegments` のテキストを `committedText` に退避し、
      確定テキスト/コピー内容が失われないようにする。
- [ ] purge 後に `confirmedSegments` / `unconfirmedSegments` / `lastConfirmedSegmentEndSeconds` を
      リセットし、`lastBufferSize` を残バッファ長以下に補正する（`nextBufferSize` が負やズレを起こさない）。
- [ ] 語中の一瞬の無音で誤発火しないよう、一定量（マージン + 約 1 秒）溜まってからのみ切り詰める。

### B. 波形を transcribe ループから分離
- [ ] `updateEnergy` を独立した短周期（約 50ms）タイマー/ループで回し、長い transcribe 中でも
      `appState.bufferEnergy` が更新され続けるようにする。
- [ ] タイマーは `start()` で起動、`stop()` で確実に停止（リーク・多重起動なし）。
- [ ] `realtimeLoop` 内の `updateEnergy` 呼び出しは削除し、二重更新にしない。
- [ ] `appState`（@MainActor / @Observable）の更新は MainActor 上で行う。

### 共通
- [ ] T-001/T-002 の幻聴抑制効果を壊さない（無音区間で定型句が出ない）。
- [ ] ビルドが通る。

## 影響範囲
- `STTLocalApp/Speech/StreamingTranscriber.swift` のみ。

## 制約・前提
- `AudioProcessor.purgeAudioSamples(keepingLast:)` / `audioSamples` / `relativeEnergy` は WhisperKit 既存 API。
- クラスは `@MainActor`。タイマーコールバックの MainActor 整合に注意（`Task { @MainActor in ... }` 等）。
- 既存のスライディングウィンドウ（`slideWindowIfNeeded`）の挙動は変更しない。

## 完了の定義
- [ ] ビルド成功
- [ ] 手動検証: 発話/無音を交互にしても発話再開時に体感ラグが無い
- [ ] 手動検証: 発話中も波形が常時アニメーションする
- [ ] 手動検証: 無音区間で「ありがとうございます」等が出ない（リグレッション無し）
