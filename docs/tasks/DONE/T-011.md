# T-011: 確定/未確定テキストと推論中フラグを AppState に公開

## 目的
- UI が「確定/未確定」「推論中か」を区別できるようにするためのデータモデル整備。
- 内部の 3 層（committed/confirmed/unconfirmed）を UI まで素通しする土台（T-012 が依存）。

## 受け入れ条件
- [ ] `AppState` に `confirmedText: String` / `unconfirmedText: String` / `isInferring: Bool` を追加。
- [ ] `AppState.currentText` を computed `{ confirmedText + unconfirmedText }` に変更。
- [ ] `copyableText` のコピー結果が変更前と完全一致（確定+未確定の連結、トリム挙動も維持）。
- [ ] `StreamingTranscriber` が `confirmedText`(=committedText+confirmedSegments) と
      `unconfirmedText`(=unconfirmedSegments) を別々に反映する。境界の生スペースを壊さない。
- [ ] `isInferring` が `pipe.transcribe(...)` の直前 true・直後 false（`defer` で確実に倒す）。
- [ ] `stop()` 完了後に `isInferring == false`。
- [ ] `AppDelegate.startRecording` のリセットを confirmedText/unconfirmedText 初期化へ更新。

## 影響範囲
- `STTLocalApp/State/AppState.swift`
- `STTLocalApp/Speech/StreamingTranscriber.swift`
- `STTLocalApp/App/AppDelegate.swift`（録音開始時リセットのみ）
- `STTLocalAppTests/`（不変条件テスト追加可）

## 制約・前提
- **タイミング中立**: 音声パイプライン（窓・clipTimestamps・スライド・minNewAudioSeconds）は不変。
- 表示用トリムはここでは行わない（UI 側で実施）。確定↔未確定の境界スペースを保持。
- 設計: `docs/plan/inference-status-and-waveform.md` の T-011 節。
