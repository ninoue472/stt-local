# T-024: 言語選択UIをトグル→ドロップダウンに変更

## 目的
- T-023 で実装した JA/KO の2値トグルを、**ドロップダウンリスト**に変更する（ユーザー要望）。
- 機能・永続化ロジックは T-022/T-023 のまま。UI 表現のみ差し替える。

## 依存
- T-022（`AppState.language`）/ T-023（`LanguageToggle`）が前提。同ブランチ `feat/t-022-language-switch` 上で作業。

## 受け入れ条件
- [ ] `PanelRootView` の言語UIが**ドロップダウン**（SwiftUI `Menu` もしくは `Picker(...).pickerStyle(.menu)`）になっている。トグル/セグメントではない。
- [ ] ドロップダウンの選択肢は「日本語」「한국어」の2つ。現在選択中の言語がラベルに表示される。
- [ ] 選択を変えると `appState.language`（"ja"/"ko"）が更新され、永続化される（既存経路）。
- [ ] `appState.phase == .ready` のときのみ操作可。それ以外（`.recording`/`.processing`/`.downloadingModel`/`.loadingModel`）は `disabled`。
- [ ] HUD ダークテーマに馴染む見た目。右上ヒント行の配置・`PanelHeightKey`（動的リサイズ）を壊さない。
- [ ] 旧 `LanguageToggle`（カプセル2値）の残骸が残っていない（置換 or リネーム）。
- [ ] ビルドが通る。

## 影響範囲（触ってよい）
- `STTLocalApp/UI/PanelRootView.swift` のみ。新規ファイルは作らない（プロジェクト再生成回避）。

## 触ってはいけない
- `AppState` / `Settings` / `StreamingTranscriber` / `DecodingPresets`（T-022 の確定ロジック）。UI のバインドのみ。

## 制約・前提
- バインド先は `appState.language`（String, "ja"/"ko"）。
- 表示はフル表記「日本語 / 한국어」。略号 JA/KO は使わない。
- 設計: `docs/plan/korean-language-support.md`。

## 完了の定義
- [ ] ビルド/lint クリーン（`CC`/`CXX` unset）
- [ ] 実機確認（人手）: ドロップダウンで ja↔ko 切替 / 録音中は無効
