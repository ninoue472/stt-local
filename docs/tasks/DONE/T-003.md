# T-003: XCTest ハーネス整備 + HallucinationFilter 単体テスト

## 目的
- 現状リポジトリにテストターゲットが無い。`HallucinationFilter`（T-002, 純粋関数）を
  リグレッションから守るため、テストハーネスを整備し単体テストを追加する。

## 受け入れ条件
- [ ] `generate_project.rb` に XCTest（unit test）ターゲット `STTLocalAppTests` を追加し、
      `ruby generate_project.rb` でテストターゲット付き .xcodeproj が再生成される。
- [ ] `STTLocalAppTests/HallucinationFilterTests.swift` を追加し、以下を検証:
      - blocklist 一致 + 高 noSpeechProb（>=0.4）→ 除去される
      - blocklist 一致 + 低 noSpeechProb かつ 高 avgLogprob（実発話相当, > -0.7）→ 残る
      - blocklist 一致 + 低 noSpeechProb かつ 低 avgLogprob（<=-0.7）→ 除去される
      - blocklist 非一致 → 常に残る
      - normalize: 「ご視聴ありがとうございました。」「 ありがとうございます 」が正規化一致
- [ ] `xcodebuild test` で全テストが pass する。

## 影響範囲
- `generate_project.rb`（テストターゲット定義の追加）
- `STTLocalAppTests/`（新規ディレクトリ・テストファイル）

## 制約・前提
- T-002 完了後（`HallucinationFilter` 実装後）に着手。
- アプリ本体のビルド・既存挙動を壊さないこと（ターゲット追加が本体に影響しない）。
- テストターゲットから `HallucinationFilter` を参照できるよう `@testable import` 構成にする。

## 完了の定義
- [ ] `ruby generate_project.rb` 成功、アプリ本体ビルドも従来どおり成功
