# T-002: 既知幻聴フレーズの信頼度ゲート付きポストフィルタ

## 目的
- VAD をすり抜けた無音ハルシネーション（環境ノイズを音声誤検出した場合など）を、
  既知定型句 blocklist ＋ 信頼度ゲートで二重に除去する。spec の対策 B。

## 受け入れ条件
- [ ] 新規 `STTLocalApp/Speech/HallucinationFilter.swift` を作成する。
- [ ] blocklist（`Set<String>`）に最低限以下を含む:
      「ご視聴ありがとうございました」「ご視聴ありがとうございます」
      「ありがとうございました」「ありがとうございます」
- [ ] `normalize(_:)`: 前後空白・空白文字・句読点/記号（。、．，!?！？ 等）を除去した文字列を返す。
- [ ] `isHallucination(_ s: TranscriptionSegment) -> Bool`:
      `normalize(s.text)` が blocklist に**完全一致** かつ
      (`s.noSpeechProb >= 0.4` または `s.avgLogprob <= -0.7`) のとき true。
- [ ] `filter(_ segments:) -> [TranscriptionSegment]`: `isHallucination` が true のものを除く。
- [ ] `StreamingTranscriber.transcribeStep` で `results.flatMap(\.segments)` の結果に
      `HallucinationFilter.filter` を適用してから `updateSegments` に渡す。

> 注: 本リポジトリには XCTest ターゲットが存在しない。テストハーネス整備＋単体テストは
> **T-003 に分離**した。本タスクではテストは作らず、実装・結線・ビルド成功までを範囲とする。
> `HallucinationFilter` は副作用のない純粋関数として書き、T-003 で後からテスト可能にしておくこと。

## 影響範囲
- `STTLocalApp/Speech/HallucinationFilter.swift`（新規）
- `STTLocalApp/Speech/StreamingTranscriber.swift`（`transcribeStep` のセグメント取得行 1 箇所）

## 制約・前提
- `TranscriptionSegment` のフィールド: `text`, `noSpeechProb`, `avgLogprob` を使用（WhisperKit 既存）。
- フィルタは `updateSegments` の前に適用すること（除外セグメントを確定状態に入れない）。
- 完全一致のみ。部分一致は実発話（「〜ありがとうございます。続いて…」）を巻き込むため禁止。
- 閾値（0.4 / -0.7）は定数で `HallucinationFilter` に集約。マジックナンバーを散らさない。
- T-001 完了後に着手（同関数の編集衝突回避）。
