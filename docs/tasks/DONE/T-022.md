# T-022: 言語切替の基盤（ja/ko デコード切替・フィルタ条件分岐・永続化）

## 目的
- 韓国語対応の土台。多言語モデルはそのままに、デコード言語を ja/ko で切り替えられるようにする。
- 言語は録音セッション境界で確定させ、録音中の言語混在を防ぐ。
- UI は本タスクでは作らない（T-023 が担当）。AppState に状態だけ用意する。

## 受け入れ条件
- [ ] `DecodingPresets` が言語を引数で受け取る（例: `streaming(language:noSpeechThreshold:)`）。`ja` で従来と同一の `DecodingOptions` を返す。
- [ ] `StreamingTranscriber` が `start()` で `Settings.shared.language` を**スナップショット**し、`transcribeStep` はその保持値を使う（録音中の Settings 変更に影響されない）。
- [ ] `HallucinationFilter.filter` の適用が `language == "ja"` のときのみ。`ko` のときは raw セグメントを素通し。
- [ ] `AppState` に `var language: String` を追加。初期値は `Settings.shared.language`。set 時に `Settings.shared.language` へ永続化される。
- [ ] 言語切替でモデル再ロード/再ダウンロードのコードパスに変更がない（`WhisperEngine` / `AppDelegate.prewarmWhisper` 不変）。
- [ ] 既存 `HallucinationFilterTests` が pass（日本語フィルタのロジック不変）。
- [ ] ビルドが通る。

## 影響範囲（触ってよい）
- `STTLocalApp/Speech/DecodingPresets.swift`
- `STTLocalApp/Speech/StreamingTranscriber.swift`
- `STTLocalApp/State/AppState.swift`
- （必要なら）`STTLocalApp/State/Settings.swift`（既存 `language` をそのまま使えるなら変更不要）

## 触ってはいけない
- `WhisperEngine.swift` / `AppDelegate.swift`（モデルロード経路）。
- `HallucinationFilter` の判定ロジック本体（呼び出し条件のみ呼び出し側で分岐）。
- 音声パイプラインのタイミング系（`maxWindowSeconds`/`overlapSeconds`/`minNewAudioSeconds` 等）。

## 制約・前提
- 言語の許容値は `ja` / `ko` の2つ。UI(T-023) が2択を保証するため、不正値の正規化は不要。
- `@Observable` AppState で `language` の永続化は `didSet { Settings.shared.language = language }` 等、単純な方法でよい。
- 設計詳細: `docs/plan/korean-language-support.md`。
