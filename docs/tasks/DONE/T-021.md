# T-021: モデルキャッシュ未検出で毎回再DLされるバグ修正

## 目的
- 「初回のみ800MB DL」のはずのモデル準備画面が毎回出る（再DL）バグを解消し、
  2回目以降はキャッシュから即ロードする。

## 受け入れ条件
- [x] 2回目以降の起動でモデルが再ダウンロードされない（キャッシュ読込）。
- [x] キャッシュ済み起動時は「初回のみ800MB DL」文言を出さず、準備中スピナーのみ表示。
- [x] tokenizer がオフライン（キャッシュ）から解決され、録音時に tokenizerMissing にならない。
- [x] ビルドが通る。

## 実装（Claude 直接）
- `Speech/WhisperEngine.swift`:
  - `existingLocalModelFolder` に WhisperKit 標準保存先
    `modelsRoot/models/argmaxinc/whisperkit-coreml/<model>` を検出候補へ追加。
  - ローカル経路に `downloadBase: modelsRoot` を付与（tokenizer オフライン解決）。
  - `isModelCached(modelName:)` を追加。
- `App/AppDelegate.swift`: `prewarmWhisper` でキャッシュ有無により `.loadingModel` /
  `.downloadingModel` を出し分け。

## 検証
- ビルド: `env -u CC -u CXX xcodebuild build` → BUILD SUCCEEDED。
- 実起動: `…/whisperkit-coreml` 配下に新規書き込みなし（再DLなし）をファイル mtime で確認。
- 詳細・再現手順: `docs/knowledge/whisperkit-model-cache-detection.md`。
