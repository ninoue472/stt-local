# T-012: 確定/未確定の色分け表示 ＋ 推論ステータスバッジ

## 目的
- 「いま何が起きているか」をユーザーへ伝える。確定/未確定を色で、推論中をバッジ脈動で示す。

## 受け入れ条件
- [ ] `TranscriptView` が確定=通常色、未確定=グレー薄色で表示（Text 連結で別 `foregroundStyle`）。
- [ ] 未確定の末尾に進行を示す `…` を付ける（`.ready` 時は付けない）。
- [ ] 未確定→確定の昇格で表示色が薄→濃へ変わる。
- [ ] `.ready` は `lastFinalText` を全文通常色で表示。
- [ ] 新規ステータスバッジを `MainBar` 左カラム（波形直上）に表示:
  - [ ] `.recording`+`isInferring` / `.processing` → ドット脈動＋「推論中…」
  - [ ] `.recording`+`!isInferring` → 静的な淡ドット＋「聞いています」
  - [ ] `.ready`/その他 → 非表示
- [ ] ドット脈動は `isInferring` に同期（true で脈動、false で停止）。
- [ ] 表示トリムは「全体先頭の空白除去」程度に留め、確定↔未確定の境界スペースを壊さない。

## 影響範囲
- `STTLocalApp/UI/TranscriptView.swift`
- `STTLocalApp/UI/PanelRootView.swift`（MainBar にバッジ配置）
- 必要なら `STTLocalApp/UI/` に新規 `StatusBadge.swift`
  （新規ファイル追加時は `generate_project.rb` での再生成が必要 — `docs/knowledge/new-source-file-requires-project-regeneration.md`）

## 制約・前提
- T-011 で追加される `confirmedText`/`unconfirmedText`/`isInferring` に依存。
- ダークパネル前提。薄色は実機で視認性を微調整（薄すぎ/濃すぎ回避）。
- 既存 `StatusIcon`（録音中の waveform 記号）は変更しない。
- 設計: `docs/plan/inference-status-and-waveform.md` の T-012 節。
