# T-023: パネル内 言語トグルUI（日本語 / 한국어）

## 目的
- フローティングパネル内で日本語/韓国語を切り替えられるUIを提供する。
- 言語は次回録音から適用される設計のため、録音中・処理中は操作不可にして挙動を明確にする。

## 依存
- **T-022 が前提**（`AppState.language` と永続化が存在すること）。

## 受け入れ条件
- [ ] `PanelRootView` の `MainBar` 内に言語切替UI（`Menu` か2値セグメント）がある。
- [ ] 現在の言語が一目で分かる（"日本語 / 한국어"、省スペース時 "JA / KO" でも可）。
- [ ] 選択を変えると `appState.language` が更新され、永続化される（T-022 の経路）。
- [ ] `appState.phase` が `.ready` 以外（特に `.recording` / `.processing` / `.downloadingModel` / `.loadingModel`）のとき UI が無効（disabled）。
- [ ] HUD のダークテーマ・既存ボタン群のトーンに馴染むスタイル。録音操作（マイク/コピー/閉じる）と視覚的に競合しない配置。
- [ ] パネルの動的リサイズ（`PanelHeightKey`）を壊さない。
- [ ] ビルドが通る。

## 影響範囲（触ってよい）
- `STTLocalApp/UI/PanelRootView.swift`
- 必要なら小さな UI 部品ファイルの新規追加（`STTLocalApp/UI/` 配下）。
  - 新規 .swift を足す場合は project 再生成が要る点に注意（`docs/knowledge/new-source-file-requires-project-regeneration.md`）。可能なら `PanelRootView.swift` 内の private View で完結させる。

## 触ってはいけない
- `AppState` の言語ロジック（T-022 で確定済み。UI はバインドのみ）。
- 録音/推論パイプライン。

## 制約・前提
- バインド先は `appState.language`（String, "ja"/"ko"）。
- 設計詳細・配置方針: `docs/plan/korean-language-support.md`。

## 完了の定義
- [ ] 全テスト pass
- [ ] ビルド/lint クリーン（`CC`/`CXX` unset。`docs/knowledge/build-requires-unset-cc-cxx.md`）
- [ ] 実機確認: ja→ko→ja 切替で表示言語が切り替わる / 再起動後保持 / 録音中は無効
