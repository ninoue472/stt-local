# レビュー: T-013 波形固まり修正（推論を MainActor から外す）＋感度調整

実装: Codex / レビュー: Claude / 結果: **コードレビュー承認・ビルドOK／実機ランタイム確認は必須（保留）**

## 実装方式
- `StreamingTranscriber` を `@MainActor final class` → **`actor`** へ変更。
  推論ループ（`transcribe` の同期前後処理を含む）が actor のエグゼキュータ＝バックグラウンドで動き、
  MainActor は `MainActor.run` の短い UI 更新時のみ使用。
- `appState` 書き込み（`bufferEnergy`/`confirmedText`/`unconfirmedText`/`isInferring`/`phase`）は
  すべて `await MainActor.run { [appState] in ... }` に統一。
- 波形: タップコールバック → actor の `applyEnergy` → `MainActor.run` で `bufferEnergy` 反映。
- `WaveformView.normalizedEnergy`: `value * 3.0` のゲイン後 `pow(..., 0.72)`、`min(1, ...)` で張り付き抑制。

## 並行安全性の確認（コードレビュー）
- **凍結解消の理屈**: `await pipe.transcribe` 中は actor が解放され、`applyEnergy` が割り込んで
  MainActor へ hop → 波形が推論中も更新される。MainActor は重い同期処理を持たなくなる。
- **デッドロックなし**: `start()`/`stop()` は MainActor（AppDelegate）から `await` 呼び出し。
  呼び出し側 MainActor は await 中に解放されるため、actor 内の `MainActor.run` は安全に実行。
- **停止整合**: `stop()` で `isRunning=false` → transcribe 復帰時 `guard isRunning` で結果書き戻し防止。
  `transcribeStep(_ pipe:)` は pipe をローカル引数で保持するため `self.pipe=nil` 後も安全に完了。
  `assembledText()` の最終テキストは従来と同一構成。
- **データ競合**: 共有可変状態（segments/lastBufferSize 等）は actor 直列実行で保護。
  MainActor.run に渡すのは値型（[Float]/String）のみ。`appState` は @MainActor 型。
