## 挙動の確認（バッファ境界）
- 無音中: buffer は prune により **1.5s〜2.5s に収束**（2.5s 超で 1.5s へ）。発話再開時の transcribe が軽量に保たれる → 遅延解消。
- `lastBufferSize = min(lastBufferSize, keep)`: 直前 transcribe 後は lastBufferSize ≫ keep のため = keep となり、prune 直後 nextBufferSize=0 で即時再発火しない。早期（buffer 小）でも guard 2.5s で守られ、benign。
- prune が残す末尾 1.5s が発話頭の onset マージン → 発話再開時のクリップ防止。

## 指摘 / 注意

- T-001/T-002 の幻聴抑制は transcribe 経路を変えていないため維持される。
