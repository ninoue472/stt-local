# 仕様: 韓国語対応（言語切替）

## 背景・目的

現在アプリは日本語固定で文字起こしする。ユーザーが日本語/韓国語を切り替えられるようにする。

重要な前提: 現行モデル `openai_whisper-large-v3_turbo` は**多言語モデル**で韓国語も認識できる。
よって本機能は「韓国語**モデル**を追加ダウンロード」ではなく、**デコード時の言語指定を切り替える**だけで実現する。追加ダウンロードは発生しない。

## スコープ

### やること
- 日本語(`ja`) / 韓国語(`ko`) を切り替えられる。
- 切替UIをフローティングパネル内に置く。
- 選択言語は永続化（再起動後も保持）する。既定は日本語。
- 日本語特化のハルシネーションフィルタ（YouTube締め定型句除去）は**日本語選択時のみ**適用する。韓国語時は素通し。

### やらないこと（今回のスコープ外）
- 韓国語特化モデルの追加ダウンロード。
- 韓国語向けハルシネーションフィルタの新設（将来の別タスク）。
- 自動言語判定。
- 2言語以上（ja/ko 以外）の追加。将来追加しやすい形にはするが、UIは ja/ko の2択に限定。

## 機能仕様

### 言語切替の適用タイミング
- 言語は**録音開始時点（`StreamingTranscriber.start()`）でスナップショット**する。
- 録音中に言語を変えても、**実行中の録音には影響しない**（次回録音から適用）。
  - 理由: 1セッション内で確定済み(ja)と未確定(ko)が混在するのを防ぎ、確定境界ロジックの一貫性を保つため。
- これを明確にするため、切替UIは**録音中・処理中は無効**（操作不可）とし、`.ready` 状態でのみ操作できる。

### デフォルトと永続化
- 既定言語は `ja`（現状維持）。
- 選択は `UserDefaults`（既存 `Settings.language` キー `stt.language`）に保存。
- 既存ユーザーは保存値がないため自動的に `ja`。

### ハルシネーションフィルタの言語条件
- `language == "ja"` のときのみ `HallucinationFilter.filter(...)` を適用。
- それ以外（`ko`）はフィルタを通さず全セグメントを採用。

## 受け入れ条件（テスト可能な形）

- [ ] 起動後パネル内に言語切替UIがあり、現在の言語（日本語/한국어）が分かる。
- [ ] 言語を「한국어」に切り替えて韓国語を話すと、韓国語テキストが表示される。
- [ ] 言語を「日本語」に戻して日本語を話すと、日本語テキストが表示される。
- [ ] アプリ再起動後も最後に選んだ言語が保持されている。
- [ ] 録音中（`.recording`）・処理中（`.processing`）は言語切替UIが無効（押せない/変更不可）。
- [ ] 韓国語選択時、日本語の定型句フィルタは適用されない（コードパス上 `language=="ja"` ガードで分岐）。
- [ ] 言語切替でモデルの再ダウンロードは発生しない（同一モデルを使い続ける）。
- [ ] 既存の `HallucinationFilterTests` は引き続き pass（日本語フィルタの挙動は不変）。

## UX メモ
- UIは HUD パネルの限られた幅に収めるため、コンパクトな表現（小さなセグメント/メニュー、"日本語 / 한국어" もしくは "JA / KO"）。
- 配置は録音操作（マイク/コピー/閉じる）と競合しない位置。
