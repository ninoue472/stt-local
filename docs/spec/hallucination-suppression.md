# 仕様: 無音ハルシネーション抑制（VAD ゲート + 幻聴ポストフィルタ）

## 背景 / 問題

発話していないタイミング、または発話終了直後の無音区間に、
「ありがとうございます」「ご視聴ありがとうございました」等の**実際には話していない定型句**が
確定テキストに混入する。

### 原因（調査済み）

1. **モデルの prior**: `openai_whisper-large-v3_turbo` は学習データに日本語 YouTube 字幕を多数含み、
   締めの定型句の事前確率が極端に高い。音響的手がかりが乏しい無音・余韻区間で、この高 prior 句を出力する。
2. **VAD ゲート不在**: `StreamingTranscriber.transcribeStep` は新規 1 秒以上たまれば
   無音でも必ず `transcribe` を呼ぶ。`relativeEnergy` は波形 UI 表示にしか使われていない。
3. **幻聴破棄ロジックの無効化**: `DecodingPresets.japanese` は `temperatureFallbackCount: 0` のため、
   `compressionRatioThreshold` / `logProbThreshold` のチェックに引っかかっても区間が破棄されず採用される。

## スコープ

本仕様は **A: VAD ゲート** と **B: 幻聴ポストフィルタ** の 2 点を対象とする。
C（フォールバック回数・閾値見直し）はリアルタイム性への影響検証が必要なため**本仕様の対象外**（将来タスク）。

## 受け入れ条件（テスト可能な形）

### A. VAD ゲート
- [ ] AC-A1: 直近バッファに音声エネルギーが検出されない（`AudioProcessor.isVoiceDetected` が false）場合、
      `pipe.transcribe` を**呼ばない**。
- [ ] AC-A2: VAD でスキップした場合、`lastBufferSize` を更新しない（＝音声を捨てず、次に発話が来たら
      その区間ごと処理できる）。スキップ時は 100ms スリープして次ループへ。
- [ ] AC-A3: 無音閾値は `Settings.shared.silenceThreshold`（新規, 既定 0.3, UserDefaults キー `stt.silenceThreshold`）から取得。
- [ ] AC-A4: 既存のストリーミング確定/スライディングウィンドウ挙動を壊さない（発話が途切れず文字起こしされる）。

### B. 幻聴ポストフィルタ
- [ ] AC-B1: 既知幻聴フレーズの blocklist を定義する（最低限: 「ご視聴ありがとうございました」
      「ご視聴ありがとうございます」「ありがとうございました」「ありがとうございます」）。
      比較は前後の空白・句読点・記号を除去した正規化文字列で行う。
- [ ] AC-B2: あるセグメントの正規化テキストが blocklist に**完全一致**し、かつ
      `noSpeechProb >= 無音確率閾値`（既定 0.4）または `avgLogprob <= 低確信度閾値`（既定 -0.7）の場合、
      そのセグメントを確定/表示テキストから**除外**する。
- [ ] AC-B3: 信頼度ゲート（AC-B2 の条件）を満たさない場合は除外しない
      （ユーザーが実際に「ありがとうございます」と発話したケースを誤除去しない）。
- [ ] AC-B4: フィルタはセグメント単位で適用し、除外したセグメントは `lastConfirmedSegmentEndSeconds`・
      `committedText`・表示テキストのいずれにも残さない。

### 共通
- [ ] AC-C1: 既存ユニットテストがあれば pass、無ければ A/B のロジックに対する最小テストを追加する。
- [ ] AC-C2: 閾値はすべて `Settings` または定数で一元管理し、ハードコードを散らさない。

## 非ゴール
- C（`temperatureFallbackCount` 等デコード閾値の変更）。
- blocklist のユーザー編集 UI。
- 多言語対応（日本語のみ対象）。

## 検証方法（手動）
1. 録音開始 → 5 秒間**無言** → 停止。確定テキストが空であること（幻聴句が出ない）。
2. 録音開始 → 1 文発話 → 3 秒無言 → 停止。発話文のみが残り、末尾に定型句が付かないこと。
3. 録音開始 → 実際に「ありがとうございます」と明瞭に発話 → 停止。
   発話した「ありがとうございます」は**消えない**こと（AC-B3 の確認）。
